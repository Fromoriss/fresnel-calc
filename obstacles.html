Перешкоди між антенами

Поставте перешкоду на трасі (клікніть або потягніть по малюнку) і подивіться, як вона перекриває зони Френеля та змінює рівень сигналу. ← До калькулятора зон

Перешкода

Формули

Положення перешкоди відносно прямої видимості

u = hп − h(r₀)

Радіус n-ї зони в місці перешкоди

Rn = √( n · λ · r₀ · ρ₀ / (r₀ + ρ₀) )

Пропускання матеріалу

T = 10−A/20

Диск / куля (інтеграл за s = ρ² / (λ·L))

E/E₀ = 1 − jπ · (1 − T) · ∫ f(s) · e−jπs dsL = r₀ρ₀/(r₀ + ρ₀); f(s) — частка кола радіуса ρ, закрита перешкодою

Циліндр / хребет (інтеграл Френеля)

E/E₀ = 1 − ½(1 + j)(1 − T) · ∫ e−jπν²/2 dνν від (u − d/2) до (u + d/2), де ν = h · √( 2(r₀ + ρ₀) / (λ · r₀ · ρ₀) )

Пояснення до малюнків

  • Помаранчевий круг — перешкода діаметром d. Тягніть його по малюнку або задайте r₀ і висоту в полях.
  • Суцільна лінія — пряма видимість між антенами.
  • Заливка — зони Френеля 1–3 (чим темніша, тим менший номер).
  • Пунктир — межа 60% першої зони.
  • Товста зелена лінія — земля.
  • Нижній графік: зміна сигналу, коли перешкоду піднімають або опускають. Хвилясті піки — інтерференція зон: коли край перешкоди відкриває чи закриває наступну зону, поле то зростає, то падає. Крапка — поточне положення.

Модель скалярна (Френеля–Кірхгофа): тонкий екран у площині, перпендикулярній трасі, без відбиття від землі. Круг на малюнку намальовано в масштабі висот, а по горизонталі профіль стиснуто. Ідеально непрозорий диск точно на осі дає «пляму Пуассона»: у центрі тіні поле майже таке, як без перешкоди. Для хребта чи стіни, що тягнуться поперек траси, обирайте форму «Циліндр / хребет».
