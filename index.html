Калькулятор зон Френеля

Розрахунок радіуса зон Френеля на радіотрасі між передавальною та приймальною антенами.

Перешкоди між антенами →

Формули

Довжина хвилі

λ = c / f

Радіус n-ї зони в довільній точці траси

Rn = √( n · λ · r₀ · ρ₀ / (r₀ + ρ₀) )r₀ і ρ₀ — відстані від точки траси до передавача та приймача

Радіус у середині траси (там зона найширша)

Rn = ½ · √( n · λ · (r₀ + ρ₀) )

Мінімум вільного простору

R₆₀ = 0,6 · R₁

Лінія прямої видимості

h(x) = h₁ + (h₂ − h₁) · x / (r₀ + ρ₀)x — відстань від передавача, h₁ і h₂ — висоти антен

Дальність прямої видимості

rпр.в. [км] = 4,12 · ( √h₁ [м] + √h₂ [м] )4,12 — з урахуванням тропосферної рефракції, без неї 3,57

Пояснення до малюнка

  • Пер. і Пр. — передавальна та приймальна антени. Вертикальні лінії — їхня висота над землею (h₁ і h₂).
  • Суцільна лінія — пряма видимість між антенами.
  • Темна заливка — перша зона Френеля. Саме в ній проходить основна частина енергії хвилі.
  • Середня заливка — друга зона Френеля.
  • Світла заливка — третя та наступні зони.
  • Пунктир — межа 60% першої зони. У ній не повинно бути перешкод.
  • Товста зелена лінія — земля (висота 0 м).
  • R₁ — радіус першої зони в середині траси, де зона найширша.

Горизонтальна вісь — відстань від передавача, км. Вертикальна — висота над землею, м. Масштаби осей різні: по вертикалі профіль розтягнуто, щоб зони було видно. У формулах r₀ і ρ₀ — відстані від точки траси до передавача й приймача; в середині траси r₀ = ρ₀ = (r₀ + ρ₀) / 2.
